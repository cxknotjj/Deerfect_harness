## 三、口播全文（连读版，约 640 字 / 3 分 40 秒）

这是一个跑在智算云模型服务上的多智能体编排平台——Deerfect Harness。你只需要把任务发进来，剩下的：拆解、并行执行、汇总，它全自动完成。

它的核心是一条路由判定链：每个请求先经过 LLM 路由判定——简单问题走单 Agent 直答，不浪费算力；复杂任务才进入 StateGraph 多智能体编排。技术底座是 Java 17 加 Spring AI，模型服务来自通义千问与 DeepSeek 等智算云供应商。

使用流程非常简单：Docker 三件套一键启动主服务、MySQL 和 PostgreSQL；浏览器打开控制台，输入口令换取登录态——凭据不进前端，机器客户端走独立的 API Token 通道。

第一个演示：简单问题。注意看顶部——先显示「路由判定中」，判定完成，结果是 SIMPLE，于是直接由 general 单 Agent 回答。回答是真·逐 token 流式。简单请求不进编排，这就是第一层算力调度。

第二个演示：复杂任务。判定为 COMPLEX，进入编排。Lead 把目标拆成结构化任务书——每条都带目标、背景、约束、交付物四要素，最多四条。多个专家并行执行，信号量错峰控制并发。注意每个专家的思考内容实时折叠展示，工具调用挂在发起它的专家名下——整个过程完全可解释。最后聚合节点把并行结果汇成成稿。

接着是知识能力。平台手册已经同步进知识库——现在问它：流式连接最多允许多少个？回答给出准确数字：五十个上限，并自动标注出处，指向参数手册的对应章节——每一条结论都能溯源，数字可现场核对。检索底层是段落切分、pgvector 向量加 BM25 双路召回、RRF 融合排序。

工具生态基于 MCP 协议：兼容 Claude 同款配置文件，按服务懒连接、故障隔离。这里演示的是把存量 WMS 仓储系统包装成的只读 MCP 服务——专员查到的是真实业务数据。代码与浏览器操作全部在 Docker 沙箱里执行，宿主机零暴露。

每一次模型调用都落观测表——token、耗时精确到轮次，成本可核算。消费侧有四级预算护栏：单次编排六万 token 熔断，超限断流；子任务超时写占位跳过，聚合照常进行——一个专家翻车，不拖垮整张图。

入口不止网页：终端 CLI、QQ 机器人、REST API，同一套编排能力，多端可达。

七百多个自动化测试用例护航，可观测、可预算、可自愈——这就是 Deerfect Harness，谢谢观看。

## 四、执行备注

1. **真实性红线**：所有画面必须来自真实运行系统；wms 数据、观测记录、知识库回答不得摆拍或后期改字。若某演示当次效果不佳（如模型偶发跳过思考），重录该镜而不是造假。
2. **节奏**：镜 5 信息密度最高，字幕与口播需分主次——口播讲流程，字幕只点关键状态词（判定完成 / 任务书 / 并行 / 聚合）。
3. **备选镜头**：若总时长需压缩到 3 分钟内，优先砍镜 9（多端快切），镜 6/7 可合并为「知识 + 工具」一镜。
4. **断点续跑镜头（可选加插）**：编排中途 `Ctrl+C` 杀进程 → 重启 → 从检查点继续、已完成子任务不重跑。演示成本高，时间充裕再加。
