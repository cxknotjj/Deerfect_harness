# 平台功能与参数手册

本手册描述 Deerfect Harness 平台的核心机制与出厂参数。所有数值以 application.yaml 为唯一来源，代码中不落硬编码。

## 路由判定

每个对话请求先经 RouteJudge 做复杂度判定：SIMPLE 走 general 单 Agent 直答，COMPLEX 进入 StateGraph 多智能体编排。判定调用使用独立连接池，读超时 10 秒，判定失败一律兜底为 SIMPLE。判定过程在界面上以进度行可视化展示，依次输出「路由判定中…」与「判定完成」。

## 编排护栏

复杂任务的拆解与执行受四重护栏保护。数量闸：Lead 拆解的子任务上限为 4 条，生效值钳制在 1 到 4 区间。时间闸：单个子任务墙钟超时 600 秒，超时在 token 边界中止并写入占位结果。并发闸：子任务并行度经信号量限制为 2，收敛下游压力。熔断闸：单次编排全程 token 消费上限 60000，真实 usage 优先记账，超限断流后剩余子任务写「预算超限跳过」占位，聚合照常执行。

## 上下文预算

输入侧分四层裁剪：会话历史 4000 token、Lead 拆解 prompt 4000 token、聚合 prompt 12000 token、工具结果注入 5000 token。输出侧按角色分档：Lead 拆解 4000、最终回答 8000、专家单次输出 4000。子任务任务书单条上限 2000 字符。全部预算键统一支持 0 值语义，0 表示该层不限制。

## 超时梯队

链路超时分层设置：路由判定读超时 10 秒；首帧超时 20 秒，用于零帧黑洞连接的快速判死；流空闲看门狗 120 秒；读超时 300 秒；子任务墙钟 600 秒。可重试错误口径统一为超时、网络类 IO、5xx、429 与 408，最大尝试 3 次，重试退避采用非阻塞延迟。

## 观测与保留

每次 LLM 调用按模型轮次落 llm_call_log，记录真实 prompt 与 completion token、耗时与错误；工具调用、RAG 检索、MCP 连接事件各有独立台账。观测数据保留 90 天，每日凌晨 3 点低峰期自动分批清理，单批 1000 行。

## 接入与安全

流式连接数上限 50，超限返回 429。登录通道以口令换取 HttpOnly Cookie，有效期 168 小时并滑动续期；同一 IP 连续失败 5 次锁定 60 秒。机器通道使用 X-API-Token 请求头，比较采用常量时间算法防时序探测。
