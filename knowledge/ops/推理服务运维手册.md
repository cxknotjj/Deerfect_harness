# 智算云推理服务运维手册

本手册面向推理服务值班运维，覆盖常见故障码的判定与处置步骤。故障码一经分配永不复用。

## ERR-4102 空闲后首调黑洞

现象：服务空闲数分钟后第一次调用挂死，无任何响应帧，第二次调用恢复正常。根因是 NAT 或网关静默回收了空闲 TCP 连接，客户端连接池里残留死连接。

处置：确认客户端已启用 HTTP/1.1 与 30 秒空闲连接驱逐；检查首帧超时是否为 20 秒，零帧请求应快速判死并进入重试；确认流空闲看门狗 120 秒生效。两项都正常时该故障码不应复现，连续复现说明网络路径存在更激进的空闲回收，需联系网络组缩短回收窗口。

## ERR-5201 编排预算熔断

现象：编排过程中流被主动断开，剩余子任务写「预算超限跳过」占位，聚合注入降级说明后照常输出。这是单次编排 60000 token 消费上限触发的预期熔断，不是故障。

处置：属正常保护行为。若频繁触发，检查任务书是否过于宽泛导致专家输出过长，或评估上调编排预算。禁止为绕开熔断而关闭预算。

## ERR-6307 向量库不可用

现象：RAG 检索返回空，回答不附出处，聊天本身不受影响。根因是 PostgreSQL 未启动或 vector 扩展未创建。

处置：启动 PostgreSQL 并以超级用户执行 CREATE EXTENSION vector；确认应用为懒连接设计，向量库恢复后无需重启。检索超时上限 10 秒，降级为空属预期行为。

## ERR-7104 MCP 连接失败

现象：某 MCP server 的工具面为空，其他 server 不受影响。根因是该 server 启动晚于主服务或地址配置错误。

处置：确认 mcp-config.json 中该 server 的 command 或 url 配置正确；重启主服务以重新发现工具。连接失败按 server 隔离，单个 server 不可用不拖垮其余工具。

## ERR-8101 登录限流锁定

现象：登录接口返回锁定提示。根因是同一 IP 连续失败 5 次触发 60 秒锁定，锁定期间不执行口令比较。

处置：等待 60 秒自动解锁。锁定机制用于抵御口令爆破，不可关闭。
