# task-checklist 使用约定

本目录存放可执行的任务清单，一个 Markdown 对应一个任务主题。

## 记录约定

1. 每个任务使用 GitHub 风格复选框：
   - `- [ ]` 表示未完成
   - `- [x]` 表示已完成
2. 完成任务后，把对应条目的 `- [ ]` 改为 `- [x]`，不要删除条目；可在条目下补一行结果与日期。
3. 当一个 Markdown 里的**所有复选框**都变成 `- [x]` 时，说明该主题任务已全部完成，可以直接删除这个文件（无需归档）。
4. 新增清单建议命名为 `<主题>.md`，文件头部写清范围、创建日期和待办数量。
5. 清单只放可执行任务；背景与详细分析放 `docs/`，清单中保留简短背景即可。
